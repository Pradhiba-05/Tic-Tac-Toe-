# Tic-Tac-Toe

A polished, responsive Tic-Tac-Toe game built with browser-native technologies. Play a quick local match with a friend or challenge the computer in a clean, modern interface.

## Features

- Player vs Player and Player vs Computer modes
- Smart computer moves with wins, blocks, center, and corner strategy
- Win, draw, and occupied-cell detection
- Winning-cell highlight and subtle game animations
- Persistent scoreboard using `localStorage`
- Reset scores and restart-round controls
- Responsive layout for desktop, tablet, and mobile
- Keyboard-friendly controls and visible focus states
- GitHub Pages compatible with no build step

## Technologies

- HTML5
- CSS3
- JavaScript

## How to Run

1. Download or clone this repository.
2. Open `index.html` directly in a modern web browser.
3. Choose a game mode and start playing.

No npm, server, or build command is required.

## GitHub Pages Deployment

1. Push the project to a GitHub repository.
2. Open the repository's **Settings** tab.
3. Select **Pages** in the left navigation.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and the `/root` folder.
6. Click **Save**, then open the published URL once GitHub finishes deploying.
