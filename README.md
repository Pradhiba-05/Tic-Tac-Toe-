## ✨ About the Project

Tic-Tac-Toe is a classic two-player strategy game redesigned with a **modern and interactive user interface**.

The project focuses on creating a smooth gaming experience using only **HTML, CSS and vanilla JavaScript**, without relying on frameworks or external libraries.

Players can compete against another player or challenge the computer while keeping track of their scores.

---

* 🎮 Player vs Player mode
* 🤖 Player vs Computer mode

## 🎯 Game Modes

### 👥 Player vs Player

Play against a friend on the same device.

Players take turns placing:

**❌ X → ⭕ O → ❌ X → ⭕ O**

The first player to complete a row, column or diagonal wins.

### 🤖 Player vs Computer

Challenge the computer and try to beat it.

The computer automatically makes its move after the player's turn.

---

## 🏆 Winning Conditions

A player wins when they complete any of these:

```text
❌ ❌ ❌
⭕ ❌ ⭕
⭕ ⭕ ❌
```

Or:

```text
❌ ⭕ ⭕
❌ ❌ ⭕
❌ ⭕ ⭕
```

Or a diagonal:

```text
❌ ⭕ ⭕
⭕ ❌ ⭕
⭕ ⭕ ❌
```
